# 🥔 Potato Disease Detection using CNN

This project is a deep learning-based model for detecting potato plant diseases using Convolutional Neural Networks (CNN). It classifies leaf images into three categories: **Early Blight**, **Late Blight**, and **Healthy**. Built using the popular **PlantVillage** dataset and implemented with **TensorFlow** in Python.

---

## 🔍 Project Overview

Potatoes are among the most important food crops globally, and plant diseases like early and late blight can significantly reduce crop yield. This model provides a reliable and intelligent way to detect these diseases early using leaf images, enabling farmers or agricultural professionals to take quick action.

---

## 📌 Features

- 🧠 Deep Learning model (CNN) with high accuracy
- 📊 Achieved **99% accuracy** on validation set
- 🏷 Trained on [PlantVillage dataset](https://www.kaggle.com/datasets/emmarex/plantdisease)
- 📁 Includes Jupyter Notebook for training and evaluation
- 📱 Future deployment plan: Mobile app / Web app
